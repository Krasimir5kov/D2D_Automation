## Locator Quality Issues

**64 of 66 elements (97%) have NO stable locator attribute (no data-testid, no aria-label, no id).**

Elements relying only on CSS class or position:

- **#1** `a` "Widget Versions" — no attributes; fallback: `page.getByRole('link', { name: /Widget Versions/i })`
- **#2** `a` "Abmelden" — logout link; fallback: `page.getByRole('link', { name: /Abmelden/i })`
- **#3–#9** `a` Portal-level nav links (Home, Door 2 Door, Timey, Cockpit-Leistungspositionen, Case Comments, Case Document Viewer, Address List) — use CSS classes `nav-link` / `nav-link active` only; fallback: `getByRole('link', { name: /…/i })`
- **#10–#15** `a` D2D sidebar nav links (Baulose, Objekte, Sales Action, Benutzerverwaltung, Importe, Konfiguration) — no attributes, deep DOM path; fallback: `getByRole('link', { name: /…/i })`
- **#17** `button` (empty) — icon-only search button with class `search-button icon-a1-lupe`; **no accessible name — critical accessibility violation**; currently only locatable via `.search-button` CSS selector (fragile)
- **#18–#20** `button` Benutzer erstellen / Team erstellen / Admin A1 erstellen — class `normal link` only; note: these belong to the Benutzerverwaltung panel, not the Importe page itself
- **#21–#23** `a` BENUTZER (973) / TEAMS (76) / ORGANISATIONEN (34) — tab-like nav; `#23` has obfuscated class `tlg0tqU99TSKEMGoxECw`
