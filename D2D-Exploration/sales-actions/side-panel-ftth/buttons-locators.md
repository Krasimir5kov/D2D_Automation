## Missing Stable Attributes

**Zero `data-testid` values detected across all 5932 elements.**  
This is the single most impactful finding: there are no stable test identifiers anywhere on the page.

### Priority list — elements that need `data-testid` or `aria-label` immediately:

| Element | Current HTML | Problem | Fix |
|---|---|---|---|
| Search field | `<input id="sales-actions-search-field" ...>` | No `<label>` associated; aria violation | Add `<label for="sales-actions-search-field">` or `aria-label`; add `data-testid="sales-actions-search-input"` |
| Search button | `<button class="search-button icon-a1-lupe">` | No accessible name, CSS-class-only locator | Add `aria-label="Suche"` and `data-testid="sales-actions-search-button"` |
| alle Filter button | `<div role="button" class="TwnxyiK4zioNv_1I44Bx">` | Generic div, hashed class, no id | Replace with `<button data-testid="sales-actions-filter-all">alle Filter</button>` |
| Column header: Baulos/Einsatzname | `<div role="button" class="HePyFz5n_qN7wvTgUrv1">` | Generic div, hashed class | Add `data-testid="col-sort-baulos"` |
| Column header: Organisation | same pattern | same | `data-testid="col-sort-organisation"` |
| Column header: Regime | same pattern | same | `data-testid="col-sort-regime"` |
| Column header: Phase | same pattern | same | `data-testid="col-sort-phase"` |
| Column header: Termin | same pattern | same | `data-testid="col-sort-termin"` |
| Column header: Immobilienart | same pattern | same | `data-testid="col-sort-immobilienart"` |
| Column header: Status | same pattern | same | `data-testid="col-sort-status"` |
| Column header: Aufgabe | same pattern | same | `data-testid="col-sort-aufgabe"` |
| Column header: Ergebnis | same pattern | same | `data-testid="col-sort-ergebnis"` |
| Column header: Planskizze | same pattern | same | `data-testid="col-sort-planskizze"` |
| Column header: Bestellung über D2D | same pattern | same | `data-testid="col-sort-bestellung-d2d"` |
| Chevron icon buttons (×11) | `<div role="button" class="gucci-icon-button-v2 secondary">` | No name, icon-only, nested inside labelled div | Add `aria-label="Sortierung Baulos/Einsatzname"` etc. per column |
| Table rows (×50) | `<div class="[hashed]">` | CSS-class-only, no role, no identifier | Add `data-testid="sales-action-row-{id}"` using row data |
| Row action buttons (×66) | `<button>` with icon only | No accessible name | Add `aria-label` describing the action + `data-testid` |
| Side panel form fields (×26) | `<input>` with no label | Critical accessibility violation | Add `<label>` or `aria-label` to every input |
| Dropdown options (×5678) | `<div>` children of wrong parent | Missing `role="option"` + `role="listbox"` parent | Restructure as proper `<select>` or ARIA listbox |
